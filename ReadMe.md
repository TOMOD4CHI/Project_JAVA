# Adding JAR Files to IntelliJ IDEA Global Libraries
**In Case u don't have (Gson and iText)**
## Steps
1. **Open IntelliJ IDEA**:
   - Launch IntelliJ IDEA and ensure you have the desired project open.

2. **Access Project Structure**:
   - Navigate to the top menu bar and click on **File > Project Structure**.

3. **Locate Global Libraries**:
   - In the **Project Structure** dialog, find the **Platform Settings** section in the left sidebar.
   - Select **Global Libraries** from the options.

4. **Add JAR Files**:
   - Click the **`+`** button or right-click in the Global Libraries section and choose **Add JARs or Directories**.
   - Browse to **\Dependencies** where the JAR files are stored.
   - Select the required JAR files and click **OK**.

5. **Apply and Save Changes**:
   - Once the JAR files are added, click **Apply** and then **OK** to save the changes
